## Cómo subirlo a GitHub

1. Descarga el ZIP final.
2. Descomprímelo.
3. Entra a GitHub.
4. Abre el repositorio:

   streamerempire / streamer-empire

5. En la rama `main`, sube todo el contenido descomprimido.
6. Reemplaza los archivos existentes.
7. Haz `Commit changes`.

## Archivos/carpetas que deben quedar en GitHub

- index.html
- CNAME
- site.webmanifest
- assets/
- legal/
- README.md
- archivos de revisión .md

## Prueba obligatoria después de publicar

1. Abre:

   https://www.streamerempire.com/

2. Presiona `Ctrl + F5`.

3. Confirma que lo primero sea la aplicación para streamers.

4. Cambia idiomas desde el selector.

5. Haz clic en:

   Apply now + upload photos

6. Debe abrir:

   https://forms.gle/f8E3WkikswMNkfTh8

7. Haz una prueba real:
   - llena el formulario,
   - sube una imagen,
   - confirma que la respuesta llegue al Google Form,
   - confirma que la imagen quede en Google Drive de streamerempire.go@gmail.com.

## Nota importante

Si Google Forms abre con un parámetro al final como `?hl=es`, `?hl=en`, `?hl=fr`, etc., es correcto. Eso sirve para intentar abrir la interfaz del formulario en el idioma seleccionado.
